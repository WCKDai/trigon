# Liberation font faces

Unmodified Liberation Sans, Serif and Mono 2.1.5 faces, licensed under the SIL Open Font License 1.1. The existing default Sans Regular file is retained separately, unchanged, in `../liberation-sans/`.

Upstream: https://github.com/liberationfonts/liberation-fonts. These files were copied from the installed LibreOffice runtime font distribution; only its separately OFL-licensed font assets were accessed. Each font name table records version 2.1.5, the Google/Red Hat copyright, and the SIL OFL licence. The complete licence is included in `OFL.txt`. No fonts from commercial CAD products are used.
